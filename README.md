# 🇯🇵 JLPT 학습 도우미

## 📋 프로젝트 개요

본 애플리케이션은 한국인이 JLPT(일본어능력시험) 학습을 지원하는 웹 애플리케이션입니다. JLPT N1~N5 레벨별 단어 학습, 독해 연습, 모의고사 등의 기능을 제공합니다.

### 제작 의도 및 배경

**왜 이 앱을 만들었는가:**

- 한국인이 JLPT를 학습하는 데 특화된 도구가 필요했음
- 검색한 단어를 자동으로 기록하고, 그 단어로 퀴즈를 생성하는 기능이 필요했음
- JLPT에 특화된 학습 환경을 제공하고 싶었음
- 이미지에서 텍스트를 추출하여 음성으로 읽어주는 기능으로 복습을 효율화하고 싶었음
- 여러 기기에서 학습 데이터를 동기화할 수 있도록 하고 싶었음
- 특히 단어의 의미를 바로 조회하는 것이 아니라, 마우스 커서를 올리기만 하면 의미를 확인할 수 있는 기능을 원했음

**니즈:**

- JLPT 시험 대비에 특화된 학습 앱의 수요
- 학습 진행 상황을 시각화하고, 지속적인 학습을 지원하는 시스템
- 오프라인에서도 사용 가능한 기능과 온라인 데이터 동기화 기능의 병행

## 🎯 주요 기능

### 1. 사용자 인증 및 계정 관리
- **로그인/회원가입 기능**: Supabase Auth를 사용한 인증 시스템
- **프로필 관리**: 사용자명, 이메일 주소 관리
- **비밀번호 변경/계정 삭제**: 안전한 계정 관리 기능
- **세션 관리**: 자동 로그인 상태 유지

### 2. 단어장 기능
- **단어 추가/삭제/편집**: 사용자만의 단어장 작성
- **검색 기능**: 일본어 단어 검색
- **숙련도 관리**: 마스터 완료/미습득 관리
- **복습 횟수 기록**: 학습 진행 상황 추적

### 3. 사전 기능
- **일본어 사전**: 로컬 사전 데이터베이스에서 검색
- **검색 기록 저장**: 검색한 단어 자동 기록
- **한자 상세 표시**: 한자에 마우스를 올리면 읽는 방법과 의미 표시 (복합어의 경우 개별 한자 의미도 표시)
- **단어 호버 기능**: 독해문 내 단어에 마우스를 올리면 즉시 의미 표시

### 4. 플래시카드 학습
- **JLPT 레벨별 학습**: N1~N5 레벨에 대응한 단어 학습
- **카드 넘기기 기능**: 클릭하여 카드를 넘겨 의미 확인
- **숙련도 관리**: "알고 있음"/"모름" 버튼으로 학습 상황 기록
- **전후 이동**: 앞뒤 단어로 이동하여 학습

### 5. 독해 연습
- **JLPT 독해 문제**: 레벨별 독해 문제 제공 (N1~N5 대응)
- **이미지에서 텍스트 추출(OCR)**: Tesseract.js를 사용한 OCR 기능
- **음성 읽기(TTS)**: Web Speech API를 사용한 읽기 기능
- **음성 제어**: 읽기, 일시정지, 정지 기능
- **텍스트 편집 기능**: OCR로 추출한 텍스트를 수동으로 편집 가능
- **단어 호버 기능**: 독해문 내 단어에 마우스를 올리면 의미 표시

### 6. 퀴즈 기능
- **검색 기록 기반 퀴즈**: 검색한 단어에서 자동으로 퀴즈 생성
- **문제 수 선택**: 5문제, 10문제, 20문제 중 선택 가능
- **4지선다 문제 형식**: 단어의 의미를 4지선다로 선택
- **진행 상황 표시**: 현재 문제 수와 진행 바로 표시
- **결과 표시**: 정답 수, 정답률 표시

### 7. 모의고사/레벨테스트
- **모의고사**: 실제 시험 형식에 준거한 문제
- **레벨테스트**: 현재 실력 측정
- **자동 채점**: 즉시 결과 표시
- **진행 상황 표시**: 문제 진행 상황 표시

### 8. 학습 진행 상황 관리
- **일일 진행 상황 기록**: 학습한 단어 수, 퀴즈 점수 기록
- **연속 학습 일수 카운트**: 학습 지속 동기 향상
- **통계 정보 표시**: 총 단어 수, 습득 단어 수, 퀴즈 정답률 등
- **진행 상황 그래프**: 학습 진행 상황 시각화

## 🛠️ 사용 기술 및 도구

### 프론트엔드
- **HTML5**: 시맨틱 마크업
- **CSS3**: 반응형 디자인, 모던한 UI
- **JavaScript (Vanilla)**: 프레임워크를 사용하지 않는 순수 JavaScript 구현
  - ES6+ 기능 활용 (async/await, 화살표 함수, 구조 분해 할당 등)
  - 모듈화된 코드 구조

### 백엔드 및 데이터베이스
- **Supabase**: BaaS (Backend as a Service)
  - **Supabase Auth**: 사용자 인증 시스템
  - **PostgreSQL**: 관계형 데이터베이스
  - **Row Level Security (RLS)**: 보안 정책 구현
  - **실시간 동기화**: 여러 기기 간 데이터 동기화

### 외부 API 및 라이브러리
- **Tesseract.js**: 클라이언트 사이드 OCR (이미지에서 텍스트 추출)
- **Web Speech API**: 브라우저 네이티브 TTS (Text-to-Speech) 기능
- **Supabase JavaScript Client**: 데이터베이스 조작

### 개발 도구
- **Node.js**: 패키지 관리, 데이터 마이그레이션 스크립트
- **npm**: 의존 관계 관리
- **Git**: 버전 관리

### 배포
- **Vercel**: 정적 사이트 호스팅
- **GitHub Pages**: 대체 배포 옵션

- **모듈화**: 기능별로 분리된 함수

## 📊 데이터베이스 설계

### 테이블 구성
- **words**: 단어 마스터 테이블 (일본어)
- **profiles**: 사용자 프로필 테이블
- **user_vocabulary**: 사용자 단어장 테이블
- **user_progress**: 학습 진행 상황 테이블
- **search_history**: 검색 기록 테이블

### 관계
- 사용자와 단어장: 1대다 관계
- 사용자와 진행 상황: 1대다 관계 (일별)
- 단어와 사용자 단어장: 다대다 관계

## 🚀 설정 및 실행 방법

### 필요한 환경
- Node.js 16 이상
- npm 또는 yarn
- 모던 브라우저 (Chrome, Firefox, Safari, Edge)

### 설치 절차

1. **리포지토리 클론**

```bash
git clone https://github.com/your-username/jlpt_study.git
cd jlpt_study
```

2. **의존 관계 설치**

```bash
npm install
```

3. **Supabase 설정**
   - `supabase_config.js.example`을 복사하여 `supabase_config.js` 생성
   - Supabase 프로젝트의 URL과 API 키 설정
   - `supabase_schema.sql`을 실행하여 테이블 생성

4. **로컬 서버 시작**

```bash
# Windows
start-server.bat

# 또는 Python 사용
python -m http.server 8000
```

5. **브라우저에서 접근**
   - `http://localhost:8000`에 접근

### 배포 방법

**Vercel에서 배포:**

1. Vercel 계정 생성
2. GitHub 리포지토리 연결
3. 환경 변수 설정 (필요에 따라)
4. 배포

자세한 내용은 `DEPLOY.md`를 참조하세요.
